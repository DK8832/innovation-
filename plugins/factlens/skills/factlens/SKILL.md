# FactLens

FactLens는 답변을 독립적인 기준 자료와 비교하는 로컬 검사기다. 검색기는 아니므로, 기준 자료는 사용자가 제공한 문서, 작업공간의 원문, 또는 현재 사용할 수 있는 검색·문서 도구에서 먼저 수집한다.

## 검증된 답변 만들기

사실 정확도가 중요한 답변에는 다음 흐름을 적용한다.

1. 먼저 답변에 필요한 독립 자료를 수집한다. 최신성이 필요한 내용은 최신 자료를 확인하고, 가능한 한 1차 자료나 공식 문서를 우선한다.
2. 질문에 대한 답변 초안을 작성한다.
3. 초안과 관련 원문을 `verify_answer`에 전달한다. `reference_texts`에는 제목, 실제 근거 텍스트, 확인 가능한 경우 URL과 게시일을 넣는다.
4. `CONTRADICTED`인 주장은 근거에 맞게 수정하거나 제거한다. `INSUFFICIENT`인 주장은 단정 수준을 낮추거나 확인되지 않았다고 밝힌다.
5. 내용이 크게 바뀌었다면 수정된 답변을 한 번 더 검사한다. 같은 답변을 반복 검사하지 말고 최대 두 번까지만 호출한다.
6. 최종 답변 끝에 한 줄로 상태를 표시한다: `FactLens 검증: 지지 N · 모순 N · 근거 부족 N · 검증 불가 N`.

사용자가 이미 답변과 기준 문서를 주고 검사를 요청했다면 바로 `verify_answer`를 호출한다. 검사 UI를 직접 사용하고 싶다고 할 때만 `open_factlens`를 호출한다.

## 근거 경계

- 답변 초안 자체나 그 초안을 바꿔 쓴 문장을 기준 자료로 사용하지 않는다.
- 독립적인 기준 자료를 확보할 수 없으면 `verify_answer`를 호출한 척하지 않는다. 최종 답변에 `FactLens 미검증: 독립 기준 자료 없음`이라고 표시한다.
- 자료가 일부 주장만 다루면 다루지 않는 부분을 검증 완료로 표현하지 않는다.
- FactLens 판정은 제공된 자료와의 일치성이지 절대적 진실 판정이 아니다.
- 출처 표기는 호스트의 일반 인용 형식을 따른다. FactLens 상태 줄은 출처 인용을 대신하지 않는다.

## 결과 설명

- `SUPPORTED`는 제공된 문서가 주장을 지지한다는 뜻이다.
- `CONTRADICTED`는 제공된 문서와 수치, 날짜 또는 긍정·부정 관계가 충돌한다는 뜻이다.
- `INSUFFICIENT`는 문서만으로 결론을 내리기 어렵다는 뜻이다.
- `UNVERIFIABLE`은 의견이나 평가 표현이라 사실 판정 대상에서 제외됐다는 뜻이다.
- 결과를 절대적 진실이나 완전한 팩트체크로 표현하지 않는다.
- 사용자에게 필요한 경우 판정 근거 문장과 도구의 한계를 함께 설명한다.
